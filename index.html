    Mobile Method (Most Reliable)
    iPhone/Android Screen Record:
    1. Tap "FULLSCREEN PREVIEW"
    2. Start your phone's screen recorder (Control Center / Quick Settings)
    3. The video auto-plays with voice + animations
    4. Stop recording when done — the file saves to Photos
    5. Upload directly to YouTube Shorts!
    Desktop Method (Best Quality)
    Auto-Record with AI Voiceover:
    1. Generate or upload a voiceover above
    2. Tap "RECORD VIDEO" — canvas + voiceover captured together
    3. Download the finished .webm file
    4. Convert to MP4 if needed (free at cloudconvert.com)

    No voiceover? Use "Fullscreen Preview" + screen recorder instead.
